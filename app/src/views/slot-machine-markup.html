Game Types

  • Choose one symbol set: Numbers, Roman, Fruits, Animals, or Emoji.
  • Selected game type defines available bet values and payout table.
  • You can change game type any time before spin.

Reward Modes

  • 1x5 Middle: one middle line only.
  • 3x5 Multi-line: full 3x5 setup with multiple paylines.
  • If you switch from 3x5 to 1x5, Joker state is removed.

Bets

  • Pick your bet from the Bet panel.
  • Total in 1x5 mode is current bet value.
  • Total in 3x5 mode is active lines × bet.

Lines And Joker In 3x5

  • In 3x5 mode you can activate multiple paylines (minimum one line remains active).
  • More active lines increase chance to hit, but also increase total stake.
  • In 3x5 mode you can buy Joker and place it on valid positions.
  • Joker adds cost and modifies eligible win combinations.

Mini Game

  • Mini game can appear after qualifying slot wins.
  • You select tickets and coin value, then numbers are drawn.
  • Final bonus payout is added back to slot balance.
